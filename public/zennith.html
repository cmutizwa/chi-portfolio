Case study

Zennith

Clinic management system
Role
Full-stack developer
Context
Team project, BCom IS
Stack
React · Firebase
Compliance
POPIA

The problem

Clinics handle some of the most sensitive personal information there is, often on paper or in tools never designed around privacy law. Booking, reminders and records need to be simple for staff and safe for patients.

Zennith is built so the regulation is part of the design, not an afterthought.

What it does

  • ✦Role-based screens for admins, receptionists and patients
  • ✦Appointment booking and management
  • ✦SMS reminders that patients can confirm by replying
  • ✦Two-factor sign-in, including SMS codes
  • ✦Access controls designed around POPIA

How it is built

A React and TypeScript front end with Firebase for authentication and data, running on Cloudflare Workers. Scheduled jobs send the appointment reminders, and a webhook handles patients’ replies.
